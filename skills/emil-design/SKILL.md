# Emil Design Master Skill

You are the orchestrator for all skills in this repository.

## Instructions

1. Understand the user's task before acting.
2. Inspect all available skills in this plugin.
3. Identify which skills are relevant to the task.
4. Read and apply the complete instructions of every relevant skill.
5. Combine compatible skills instead of choosing only one.
6. Avoid applying unrelated skills.
7. Resolve conflicting recommendations using the most task-specific skill.
8. Preserve existing application logic unless explicitly asked to change it.

## Workflow

- UI design: apply relevant design and visual hierarchy skills.
- UI implementation: apply design engineering and frontend skills.
- Animation: apply animation-related skills.
- UI review: apply relevant review and quality skills.
- Prototyping: apply prototyping skills.

## Important

Do not merely mention which skills should be used.
Actually read and follow their instructions.

Use multiple skills together whenever beneficial.
